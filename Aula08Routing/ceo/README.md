# Projeto — Aula08Routing

## Visão Geral
Aplicação web em ASP.NET Core (.NET 10.0) Minimal APIs desenvolvida para demonstrar conceitos avançados de Routing, estruturação de endpoints modulares e apresentação de conteúdo HTML dinâmico.

## Módulos do Sistema
- **Routing**: Gestão de rotas, endpoints e dados em memória de Estudantes, Cursos e Disciplinas.

## Tecnologias
- ASP.NET Core 10.0 (Minimal APIs)
- C# 12+ / .NET SDK 10.0
- HTML5 / CSS3 (Assets estáticos em `wwwroot`)
